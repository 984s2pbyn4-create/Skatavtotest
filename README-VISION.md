# СКАТ Vision 6.70 — мост к основной карте

**База:** СКАТ Vision 6.69. **Затронуты:** `vi.js`, `index.html`, `sw.js`. Дополнительные workflow-файлы перенесены из 6.69 без изменений.

## Что нового

В Vision появилась кнопка **«В основной СКАТ: нейтральные объекты»**. После распознавания и ручного подтверждения нейтральных обозначений и игровой четырёхточечной привязки она создаёт обычный редактируемый слой в основной структуре `state.arrays` СКАТ, который отображается на штатной карте и доступен через список слоёв.

Поддерживаются только следующие обобщённые обозначения: **здание / строение**, **дорога / путь**, **мост / переход**, **дерево / растительность**, **водоём**. В оригинальном СКАТ они отображаются голубыми значками с обозначением типа, а не копией военного условного знака. Типы и названия сохраняются в точках слоя.

**Точность:** это **ориентировочное размещение** по текущей видимой области главной карты, а не полноценная геодезическая привязка. Четыре точки Vision используются для выправления перспективы изображения; игровые X/Y не преобразуются в координаты СК-42 или WGS84. Перед подтверждением приложение прямо предупреждает об этом. После импорта положения на основной карте можно исправить вручную стандартными средствами СКАТ.

Военные/тактические идентификаторы знаков штатной библиотеки в основной географический слой не импортируются. Они сохраняются в отдельном игровом проекте Vision.

## Как пользоваться

1. Установите 6.70 поверх файлов 6.69 или загрузите полный пакет в GitHub (сохраняя пути). Не удаляйте имеющиеся файлы репозитория.
2. Откройте СКАТ, затем **«Ещё» → «Vision»**.
3. Загрузите изображение, нажмите **«Найти объекты»**.
4. В списке соответствий выберите нейтральные типы, например «Здание / строение», и подтвердите каждый объект.
5. Отметьте четыре точки клетки на изображении и нажмите **«Привязать подложку»**.
6. Важно: заранее отцентрируйте **основную карту СКАТ** на нужном участке. Новый импорт располагает нейтральные объекты ориентировочно по текущему охвату карты.
7. Нажмите **«В основной СКАТ: нейтральные объекты»** и прочитайте предупреждение. Подтвердите импорт.
8. Vision закроется, на основной карте появится слой **«Vision: [название проекта]»**. Воспользуйтесь стандартным списком слоёв, чтобы скрыть, показать, исправить или удалить его.
9. Повторный импорт **того же проекта** после подтверждения заменяет только слой, ранее созданный Vision для этого проекта. Слои, созданные пользователем, не затрагиваются.

## Хранение и ограничения

- Состояние штатной карты сохраняется обычным механизмом `persistNow()` СКАТ; система PIN и шифрования не изменялась.
- Локальные черновики и изображения Vision по-прежнему хранятся отдельно в IndexedDB `skat_vi`.
- **Вспомогательная фотография остаётся внутри Vision** и в этом релизе не записывается в основную базу карты, чтобы не переполнить localStorage.
- Линии, произвольные пользовательские значки, боевые обозначения и географическая привязка по реальным координатам **не входят** в этот мост.
- Для точного размещения нейтральной подложки на реальной карте потребуется отдельная согласованная картографическая функция, учитывающая CRS и контроль точности.
- Не очищайте данные сайта на iPad без экспортированной резервной копии.

## Проверка

Пройдены `node --check` для `vi.js`, `sw.js`, основного встроенного JavaScript и скриптов запуска приложения. На изолированных данных выполнены проверки: добавление нейтрального слоя без удаления имеющихся, повторный импорт без дублей, отклонение тактических обозначений, запрет импорта из активного Редактора и при заблокированном PIN, отмена пользователем, отказ при отсутствии четырёхточечной привязки.

**Не проверено:** полноценный запуск на iPad Safari, Android, Windows; реальный браузерный сценарий полностью не выполнен из-за блокировки локального тестового адреса средой; обновлённый ZIP не устанавливался в пользовательский GitHub.
